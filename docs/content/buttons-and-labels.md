# Buttons and labels

> ✗ **Don't** — "Submit" · "OK" · "Click here to export your data as a CSV file"
>
> ✓ **Do** — "Save changes" · "Delete probe" · "Export CSV"

**Buttons.** Say what happens: Save changes, Export CSV, Acknowledge alert.
Never "Submit" or "OK" alone.

**Destructive actions.** Name the thing and the consequence: Delete probe. Pair
it with a confirmation that restates what is lost.

**Cancel means abandon.** If the control only closes a panel, say Close. Do not
use Cancel for both.

**Length.** Two or three words. If a button needs more, the explanation belongs
above it, not inside it.

See also: [Button guidance](../../packages/ui/src/components/button/guidance.json).
