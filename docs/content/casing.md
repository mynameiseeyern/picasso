# Casing

**Sentence case everywhere, except proper nouns.** Buttons, labels, hints,
headings, menu items, tabs, table headers, badges, empty states and errors.

> ✗ **Don't** — "Export Csv" · "View All Alerts" · "TENANT NAME" as a column header
>
> ✓ **Do** — "Export CSV" · "View all alerts" · "Tenant name"

There is no uppercase exception for table column headers.

## Proper nouns

Clarion, Iris, Prognosis, Collaborate, Transact, Infrastructure, IR. First
mention takes the prefix — IR Collaborate, then Collaborate.

**Fixed forms.** UC & CC, HPE NonStop, Real-time Payments. Vendor and protocol
names as the vendor writes them: SIP, RTP, MOS, SBC, Teams, Webex.

The lowercase wordmarks are graphics, never copy. The product's pre-rename name
never appears in a string, file name or alt text.

## The one exception

`label/xs` is uppercase with wide tracking. Use it as an **eyebrow or overline**
only — chrome that must not read as data. Never on a button.

## Marketing surfaces

Brand CTA strings keep their title case: Get a Demo, Contact Us, Watch Video.
Product UI does not. A Picasso Button placed on a marketing page takes the brand
string.
