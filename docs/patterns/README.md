# Patterns

A component page answers "how does this Button behave". A pattern answers the
question people actually arrive with: "how do I build this screen". Each one
names the components, the width mode and the decisions already taken, so the
next screen of that kind starts from the answer rather than from a blank page.

| Page | |
|---|---|
| [Definition of done](definition-of-done.md) | The bar every screen ships against — what is checked automatically, and what you check |
| [Form page](form-page.md) | A page whose job is to be filled in and submitted |

A screen with no pattern here is not off-system — it is a pattern nobody has
written down yet. Build it from components, then raise it in the Design System
forum so the next one does not have to be worked out again.
