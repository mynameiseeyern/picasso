# Get started

Picasso has three audiences who enter it from different ends.

- **[For engineers](engineers.md)** — install, import, theme, and the rules the linter enforces
- **[For designers](designers.md)** — the Figma library, what it is authoritative for, and what it is not
- **[For agents](agents.md)** — the MCP server, and what to keep in your own repo
- **[Create a brand and apply Picasso](new-brand.md)** — a new brand in one file, and switching a product onto it

Both read [Foundations](../foundations/) and [Content](../content/). Those are
the parts of the system that are neither code nor Figma.
