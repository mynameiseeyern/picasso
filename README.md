# Picasso

Integrated Research's design system.

**The repo is the source of truth.** Figma is a consumer — it receives tokens and
is reconciled to match the code. This reverses the convention that governed the
earlier Picasso Figma work, and it applies to tokens and component APIs alike.

## Packages

| Package | What it is |
|---|---|
| `@ir/tokens` | Primitives, semantics, the Tailwind bridge, and the five theme axes |
| `@ir/ui` | React components — shadcn architecture (Radix + CVA + `cn`), Tailwind v4 |

## Getting started

```bash
npm install
npm run build:tokens     # generates packages/tokens/dist/tokens.css
npm run storybook        # component library at :6006
npm run dev:site         # docs site at :3000 (landing page + docs/ rendered)
npm run build:site       # what Vercel runs: tokens → llms → Storybook → nest → Next
npm run lint             # @shadcn/lint — design system rules, enforced
```

## The site

`apps/site` is a Next.js + Fumadocs app and is what Vercel deploys
([ir-picasso.vercel.app](https://ir-picasso.vercel.app)).

| Route | What it is |
|---|---|
| `/` | Landing page — an IR brand piece (Oswald/Poppins, core palette, the supplied logo files) |
| `/docs/…` | The `docs/` folder, rendered. Sidebar order comes from each folder's `meta.json`; a folder's `README.md` is its index page |
| `/docs/…/page.md` | The same page as Markdown (also served on `Accept: text/markdown`) |
| `/components` | Storybook, built and nested by `scripts/nest-storybook.mjs` |
| `/theming` | Theme builder — one hex → OKLCH brand ramp, neutral, radius, spacing, type; previews the `Theming/Preview` story in an iframe; exports a `themes.css` block or a `brand.json` |
| `/llms*.txt` | Generated by `scripts/build-llms.mjs`, copied to the site root |

Fonts are self-hosted in `apps/site/fonts/` (Google Fonts is not reachable from
every build environment). The brand variables in `apps/site/app/global.css` are
for the site shell only — Picasso components never use them.

## Import order matters

```css
@import "tailwindcss";
@import "@ir/tokens/tokens.css";   /* primitives + semantics (generated) */
@import "@ir/tokens/themes.css";   /* theme axes — override primitives */
@import "@ir/tokens/theme.css";    /* Tailwind bridge */
```

## Theming

Five independent axes on `<html>`, plus dark mode:

```html
<html data-brand="clarion" data-neutral="cool" data-radius="default"
      data-type="default" data-spacing="default" class="dark">
```

**Theme axes override primitives. Dark mode overrides semantics.** Semantics alias
primitives, so redefining `--palette-brand-*` re-points every downstream token for
free. Five axes × 2 modes compose by cascade, not by authoring ten sets.

## Writing components

Use the semantic utilities, never raw values or `bg-[var(--...)]`:

| Token family | Utility | Example |
|---|---|---|
| `bg/*` | `surface-*` | `hover:bg-surface-primary-emphasis-hovered` |
| `fg/*` | `content-*` | `text-content-neutral-muted` |
| `border/*` | `line-*` | `border-line-neutral-muted` |

`npm run lint` enforces this. See `AGENTS.md` for the full rules.

### For agents

**The MCP server is the way in:** `https://ir-picasso.vercel.app/api/mcp`,
read-only and unauthenticated. `apps/site/app/api/mcp/route.ts` serves four
tools — `search_picasso`, `get_component`, `get_tokens`, `get_doc` — out of
`apps/site/public/catalogue.json`, which `build:llms` writes in the same run as
the text files below, from the same sources. Setup for Claude Code, Cursor and
Copilot is on the [For agents](docs/get-started/agents.md) page.

For a tool that cannot speak MCP, `npm run build:llms` also generates five
files into `public/`, served alongside Storybook:

| File | Contains |
|---|---|
| `llms.txt` | index — one line per page |
| `llms-full.txt` | everything, concatenated |
| `llms-foundations.txt` | foundations and content |
| `llms-components.txt` | component guidance only |
| **`llms-tokens.txt`** | **every semantic token resolved to its light and dark hex** |

`llms-tokens.txt` is the important one. An agent without the resolved token
table invents hex codes; an agent with it cannot.

Point an assistant that has no MCP support at it:

```
Use Picasso design system documentation from https://ir-picasso.vercel.app/llms.txt
```

The host appears in one place — `PICASSO_DOCS_URL` in `scripts/build-llms.mjs`,
defaulting to the Vercel deployment. When Picasso moves to its own domain, set
that variable in Vercel's environment and every generated link follows on the
next build.

⚠️ **Editor configs are the exception.** Anyone who has pointed Cursor,
Windsurf or Claude Code at `ir-picasso.vercel.app` has the host saved on their
own machine, where a rebuild cannot reach it. Worth keeping the Vercel URL
resolving after the custom domain lands rather than chasing everyone's
settings.
